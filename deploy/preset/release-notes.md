本预设版基于已固定的 3.6.0，长期使用 `v3.6.0-preset.4` 作为唯一预设版部署标签。后续修复更新同一发布，安装命令不变；同一命令会安装维护后的预设版。

首次部署自动配置：

- VLESS 直连、VLESS 住宅两个节点，入站标签为 `默认直连`、`默认住宅`。
- 住宅 Socks5 出站 `默认` 及相应路由。
- 一个邮箱为 `01` 的客户端，同时关联两个入站，共用随机 UUID 和订阅 ID。
- 默认 REALITY 目标和 SNI 为 `www.samsung.com`，预设参数拒绝微软及常见微软服务域名，最小客户端版本为 `1.0.0`。
- Clash 订阅默认开启。

部署命令：

```bash
bash <(curl -fLsS https://raw.githubusercontent.com/kjxv/3x-ui/v3.6.0-preset.4/deploy/preset/install.sh)
```

登录后，在 Xray 设置 → 出站编辑 `默认`，填写住宅 Socks5 的地址、端口及认证信息，保存后导入 Clash/Mihomo 订阅。

预设只在首次部署时应用；升级或重复安装保留已有节点、账号、证书和用户配置。住宅出站不可达时不回退到 VPS 出口。
首次申请 HTTPS 证书后的目录恢复已修复，旧版初始化标记继续兼容。

维护提交在全部检查通过后更新同一标签和安装包；GitHub 发布说明记录具体提交。原 v3.6.0 视频版本及其他原有视频版本保持原样。旧预设版 `.1`～`.3` 的 Release 和标签已清理。

请允许实际入站端口、面板端口和订阅端口通过云安全组。完整说明见 `deploy/preset/README.md`。
