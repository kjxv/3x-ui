首次部署生成的节点相关标签去除个人缩写：

- 直连入站：`默认直连`
- 住宅入站：`默认住宅`
- 住宅 Socks5 出站：`默认`

对应路由同步使用这些标签。节点名称保留 VLESS 直连、VLESS 住宅；只创建一个 `01` 客户端，关联两个入站。
新安装的内部初始化标记采用通用名称，同时兼容旧版本的标记，避免升级或重试时重复创建节点。
升级已有面板会保留已保存的标签及其他配置；手动改名时需同步修改路由引用。

默认 REALITY 目标和 SNI 改为 `www.samsung.com`；预设参数拒绝微软及常见微软服务域名。
两个入站的最小客户端版本默认填写 `1.0.0`。
只创建一个邮箱为 `01` 的客户端，并关联 VLESS 直连、VLESS 住宅两个入站；两者共用随机 UUID 和订阅 ID。
升级已配置的面板保留用户配置，不自动合并或删除已有客户端。

修复首次申请 HTTPS 证书后目录切换导致 `geoip.dat` 路径错误、预设初始化中断和面板未启动的问题。
新增包含 ACME 安装目录切换、TLS 面板和 TLS Clash 订阅的回归测试。

基于本仓库已固定的 v3.6.0，首次部署自动创建 VLESS 直连与住宅两个节点、住宅 Socks5 出站、对应路由，并开启 Clash 订阅。

登录后台后，在 Xray 设置 → 出站填写住宅 Socks5 的地址、端口及认证信息，保存后导入 Clash/Mihomo 订阅使用。

预设只在首次部署时应用；重新安装和升级保留用户配置。住宅出站未配置或连接失败时，不自动回退到 VPS 出口。
面板版本、安装脚本和包内 Xray/规则文件固定。原 v3.6.0 教程版本及其安装包保持原样。

部署命令：
```bash
bash <(curl -fLsS https://raw.githubusercontent.com/kjxv/3x-ui/v3.6.0-preset.4/deploy/preset/install.sh)
```
