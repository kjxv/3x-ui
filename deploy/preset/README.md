# 3X-UI 3.6.0 默认节点预设版

固定部署标签：`v3.6.0-preset.4`。基础源码为本仓库原有的 `v3.6.0` 标签。
本预设版长期沿用这个标签和安装命令；后续修复更新同一发布，不再增加 `.5`、`.6` 等标签。同一命令会安装维护后的预设版。
原来的 v3.6.0 Release、安装包及 video-v3.6.0 教程分支保持原样。

## 一键安装

在干净的 Linux VPS 上以 root 运行：

```bash
bash <(curl -fLsS https://raw.githubusercontent.com/kjxv/3x-ui/v3.6.0-preset.4/deploy/preset/install.sh)
```

安装程序及辅助脚本固定到同一个标签，安装包全部从本仓库下载，下载后检查 SHA256。
支持 amd64、arm64、armv7、armv6、armv5、386、s390x；Windows 发布包包含同一个 preset 子命令。

## 安装后怎么用

1. 使用安装时显示的账号和后台地址登录。
2. 打开 **Xray 设置 → 出站**，编辑 `默认`。
3. 填写住宅代理供应商提供的地址、端口，以及需要时的用户名和密码，保存。
4. 复制 Clash 订阅链接，导入使用 Mihomo 内核的代理软件。
5. 选择 **VLESS 直连** 或 **VLESS 住宅**。

直连使用 VPS 的公网出口；住宅节点通过 VPS 转发到住宅 Socks5 出口。
使用白名单认证的住宅代理，需要把 VPS 的公网 IP 加入供应商的白名单。
住宅信息未填写或代理不可达时，该节点连接失败，不回退为 VPS 出口；直连节点可独立使用。

入站标签为 `默认直连` 和 `默认住宅`，住宅 Socks5 出站标签为 `默认`，对应路由同步引用这些标签。节点、客户端和订阅命名不包含个人缩写。
两个节点使用 VLESS + TCP + REALITY / Vision，两个入站关联同一个邮箱为 `01` 的客户端，共用随机 UUID 和订阅 ID；各入站的 REALITY 密钥在首次安装时独立生成。
默认端口为 443 和 8443；如被占用则选择其他可用端口，实际端口在安装结果和后台显示。
请让云安全组允许这两个入站端口、面板端口及订阅端口（默认 2096）。
如果安装时为面板配置了证书，初始订阅服务复用该证书。
默认 REALITY 目标和 SNI 为 `www.samsung.com`，最小客户端版本为 `1.0.0`。可指定其他适合服务器网络的目标，预设参数拒绝微软及常见微软服务域名。
住宅代理是否支持 UDP 取决于供应商，不支持 UDP 的代理不能提供完整的 UDP 转发。

## 保护已有配置

预设是显式的一次性初始化操作，不会在面板每次启动时执行。
重新运行安装命令会保留已有节点、住宅账号及订阅设置；删除过的节点也不会被重新创建。
初始化失败时回滚所有新增节点和设置，不留下半套配置；修正参数后重试安装即可继续初始化。
预设版关闭上游的面板更新与 Dev 更新入口。后续维护继续使用本页的固定安装命令。
手动更换 Xray 内核或规则文件会偏离本发行版的固定运行环境。

安装结果（含实际端口和订阅 ID）保存到 `/etc/x-ui/preset-result.json`，权限为 600。
Windows 首次运行前可执行 `x-ui.exe preset`，然后启动面板；重复执行会保留配置。

## 可选安装参数

- `XUI_PRESET_PUBLIC_ADDRESS`：分享链接使用的公网 IP 或域名；默认使用访问面板的主机名。
- `XUI_PRESET_DIRECT_PORT`：指定直连端口；指定端口被占用时停止初始化。
- `XUI_PRESET_RESIDENTIAL_PORT`：指定住宅端口。
- `XUI_PRESET_REALITY_SERVER_NAME`：REALITY 目标域名。

这些参数均可省略，用户正常使用只需在后台填写住宅代理信息。

## 发布和维护

`base-assets.json` 保存原 v3.6.0 的 8 个发布包校验值。
构建时重用这些包内的 Xray、规则和辅助二进制，仅替换面板程序及管理脚本。
预设工作流先检查初始化、回滚、订阅及固定更新行为，并在 Linux 上检查实际 Xray 配置和订阅。
每次修改推送至 `codex/v3.6.0-preset` 分支，完成源码、8 个平台构建及完整安装验证后，更新同一个 `v3.6.0-preset.4` 标签和 Release。
原 `v3.6.0` 标签、安装包和 Latest 标记保持原样，预设版的基础 Xray 与规则仍按 `base-assets.json` 固定。
更新前备份现有发布；替换期间先将预设发布置为草稿，完整上传包及校验值后重新公开，失败则恢复旧发布。发布说明记录具体维护提交，便于查找修复。
视频和配套文档长期使用本页的同一条命令。旧预设版 `.1`、`.2`、`.3` 的发布和标签已清理；维护历史保留在分支提交中。

## 本次修复

首次部署生成的入站、出站和路由标签去除个人缩写，住宅 Socks5 出站直接命名为 `默认`。新安装的内部完成标记和重试标记也采用通用名称；旧版本标记继续识别，以免升级时重新初始化。
升级已有面板保留用户配置，包括原先的标签；若手动改名，请同时修改对应路由引用。

修复首次申请 HTTPS 证书后预设初始化在 `/root/bin` 查找规则文件、安装提前退出的问题。
安装程序现在会恢复到 `/usr/local/x-ui` 再初始化节点和安装服务。
已部署旧预设版的用户可直接运行本页固定安装命令，账号、证书及已保存节点保留；未完成的预设初始化会继续执行。

本版首次部署只创建一个 `01` 客户端，并关联 VLESS 直连和 VLESS 住宅两个入站。升级已有面板不会自动合并客户端或覆盖用户自行修改的 SNI、UUID 和住宅信息。
